\# CodeAlpha Language Translation Tool



\## Project Overview



This project is a web-based Language Translation Tool developed as part of my CodeAlpha Artificial Intelligence Internship.



The application allows users to enter text, select a source language and target language, and translate the text using a translation API.



\## Features



\- Enter text for translation

\- Select source language

\- Select target language

\- Translate text using an API

\- Display the translated result

\- Simple and user-friendly Streamlit interface



\## Technologies Used



\- Python

\- Streamlit

\- Requests

\- MyMemory Translation API



\## How It Works



1\. The user enters text into the application.

2\. The user selects the source language.

3\. The user selects the target language.

4\. The application sends the text and language information to the translation API.

5\. The API returns the translated response.

6\. The translated text is displayed in the Streamlit application.
